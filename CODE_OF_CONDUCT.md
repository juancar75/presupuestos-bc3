# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trato respetuoso, críticas técnicas a las ideas y no a las
personas, y especial cuidado al revisar el trabajo de quien empieza.
Los mantenedores pueden editar o retirar contribuciones que no lo respeten.

Para informar de un incumplimiento, contacta de forma privada con los
mantenedores mediante los avisos de seguridad del repositorio.
